# 大库静态建站基准

运行：`python3 -B scripts/benchmark-site > /tmp/site-benchmark.json`。仅使用 Python 标准库和项目构建器，不读取真实 workspace，不联网，不写数据库，也不发布网站。临时构建目录退出时自动清理，报告只写标准输出。CI 的 Public Demo 作业运行同一命令，保留 JSON 报告7天。

## 范围与样本

`fictional-site-v1` 固定生成1千/1万张卡片、10个方向、4个标签，每张正文重复100行虚构文字，固定时间、来源标识和正文摘要。私密版输入全部标为 private；公开版输入每5张含1张 private，实际输出800/8000张。两个模式都带虚构审核说明，用于验证公开排除与私密保留。

每个规模/模式先进行一次冷构建预热，再在同一临时路径完整构建3次，包括规范化、契约校验、静态产物生成、内部校验和原子替换清理。计时不含样本生成和额外验收。报告保留3次原始耗时、中位数及最大值；3次样本不足以解释尾延迟，不报告 P95，也不设跨设备耗时硬门槛。

每次构建后检查卡片 ID、原正文和摘要、搜索 ID 与唯一正文标记、审核字段、完整站点检查和本地断链检查。公开版扫描全部产物，拒绝虚构私密正文或审核标记。对全部文件的相对路径和摘要计算构建指纹，4次结果须一致，输入样本不得被修改。三个故障/边界测试覆盖公开过滤和私密保留、搜索缺卡、公开页面混入私密标记。

## 边界

这是 canonical 数据到静态站的基准，不含原始资料导入、提炼、数据库导出、浏览器加载/解析/渲染、浏览器内存或完整发布门禁。没有执行在线健康检查或上传。

大库产物中的 JSON 可超过现有公开隐私门禁默认5 MiB文件限制，因此“构建通过”不代表“允许公开发布”。基准不调用完整发布门禁，也不提高限制；其隐私断言只验证固定样本标记和可见性排除，不替代通用凭据扫描。真实发布继续执行原有门禁。

L15 的搜索/复核逻辑与静态建站基线现已具备；桌面页面就绪、搜索和 JS 堆快照已另有[浏览器基准](browser-benchmark.md)，真实手机和进程峰值内存仍待补测。此次不根据单次数据更改产品架构。
